Why automate it

By hand, it would take

  • Several real phones and an iPad
  • A new set for every gym
  • Starting again after every app change

Automated

  • One command
  • Exact sizes Apple asks for
  • No real customer data

Choosing the screens

The computer follows one short list of screens. Today it has all 11.

  1. Home
  2. Check-in
  3. Upcoming
  4. Appointment
  5. Classes
  6. Class details
  7. Appointment types
  8. Pick a time
  9. Pick a trainer
  10. Confirm booking
  11. Account
You pickWhich screens, in which order
We update the listRemove, reorder or add screens
It runs againNew pictures, only the chosen ones

Every gym gets the same list for now. A gym can get its own list later.
